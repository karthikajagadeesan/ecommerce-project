<!-- 
  WHAT THIS SCRIPT DOES AUTOMATICALLY:
  1. Extracts the license key from the data-license attribute.
  2. Sends an API request to /api/validate-license to check if the key is active, paid, and valid for this domain.
  3. If valid, it checks the membership plan (Basic or Premium).
  4. It displays an interactive UI with 2 or 4 layout options depending on the plan.
  5. When a user selects a layout, it fetches the dynamic UI from /api/layout-data and renders the specific layout.
